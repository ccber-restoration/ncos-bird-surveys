Introduction

When applying the methods of Julien and Tyler to CCBER bird survey data collected at NCOS, it was quickly noticeable that one default U hyperparameter value had wildly different impact on different species. Thus, here, referencing the JRBP data and determined U values, I attempt to understand the criteria used to judge possible U values to select a specialized number for each example NCOS species examined.

JRBP Data Testing

For my evaluation of Julien and Tyler’s methods used to select U values, I examined all of their “diagnostic plots” while inputting the correct U values and population trend distributions per species simultaneously using a modified version of their provided R script. I do not include all of the visualizations they used here, instead providing a selection of the different types. It should be noted that my current implementation of modified script is not vectorized with purrr, which remains an area to be improved upon later.

A table of all meaningful statistics. The dispersion statistic was the most important factor in determining model fit. DIC tended to trend identically to dispersion, but with larger numbers.

Using these visualizations and statistics and another modification of the Julien-Tyler script, through trial and error, ideal U values and population distributions were determined for each of the nine example CCBER species: Common Yellowthroat, Killdeer, American Crow, Song Sparrow, Northern Shoveler, Least Sandpiper, Gadwall, Semipalmated Plover and Red-tailed Hawk. I took notes on the “diagnostic plots” output in a Google document and have comments to accompany my choices for U values and distributions.
